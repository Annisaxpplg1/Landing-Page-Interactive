LOKA BLITAR WEBSITE
===================

Cara menjalankan:
1. Ekstrak folder/ZIP.
2. Buka index.html di browser, atau buka folder melalui VS Code lalu jalankan dengan Live Server.
3. Pastikan folder assets tetap berada di samping index.html.

File:
- index.html : struktur halaman
- style.css  : layout, warna, font, responsive
- script.js  : interaksi navigasi
- assets/    : gambar yang dipotong dari screenshot referensi yang Anda kirim

Catatan:
Bagian hero memakai potongan screenshot referensi agar komposisi visualnya tetap sangat dekat dengan Figma. Karena sumber gambar adalah screenshot, bagian hero menampilkan gambar referensi sebagai satu visual; tautan navigasi tetap dibuat sebagai area klik transparan. Link WhatsApp, Instagram, dan TikTok masih berupa tujuan umum dan bisa diganti dengan akun asli.
